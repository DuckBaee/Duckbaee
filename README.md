# 한종훈

게임 클라이언트 개발자를 지향합니다.  
입력, 카메라, 피드백처럼 플레이어가 직접 체감하는 시스템을 구현하는 데 관심이 많습니다.

[웹 포트폴리오](https://duckbaee.github.io/Portfolio/) | [DISTORIA on STOVE Indie](https://store.onstove.com/games/102916)

## Focus

- Unity 기반 게임 클라이언트 개발
- FPS 반동, 카메라 피드백, 액션 입력 흐름 구현
- AR Foundation 기반 모바일 AR 게임 사이클 개발
- IOCP 서버와 Unity 클라이언트 연동 R&D
- FMOD 기반 사운드 연동 및 게임 피드백 설계
